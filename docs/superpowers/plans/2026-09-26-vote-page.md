# Vote Page Implementation Plan

> **For agentic workers:** execute task-by-task with human checkpoints (CW4). Steps use checkbox (`- [ ]`) syntax for tracking. Design: [`../specs/2026-09-26-vote-page-design.md`](../specs/2026-09-26-vote-page-design.md).

**Goal:** A standalone `vote.html` that lists the `!` (Fakt) entries and, on a second tab, the `??` (Gegenfrage) entries under one configured topic folder of one configured tenant, with ▲/▼ voting, *Bestätigen*, and source links from a `src:` attribute holding markdown link(s).

**Architecture:** No backend change. `vote.html` consumes `GET /entries`, `GET /votes`, `POST /votes` and `config.php` exactly as `app2.html` does. Shared pure helpers and the type vocabulary move out of `app2.html` into `assets/entry-core.js` (CA7, CA18); card-internal CSS moves from app2's inline `<style>` into `assets/components.css`. New config section `[vote_page]` is surfaced by `config.php`.

**Tech Stack:** Plain PHP (config only), vanilla JS, `renderMd()` from `assets/md-renderer.js`, design tokens/components from `assets/`.

## Global Constraints

- CP1/CP2: no new PHP route; `config.php` stays a standalone JSON emitter.
- CD1/CD3/CP3: no data-format or `?format=` change; `parseEntry()`/`formatEntry()` untouched.
- CG-DS1..5: tokens only for spacing/type, no out-of-system colours, 44 px hit areas, `:focus-visible` only.
- CA15/CA16: every user-facing error is plain German + full `console.error` detail.
- CA18: labels come from `TYPE_DEFS`; the page introduces no new type label, colour or icon.
- Tests: PHP via `just unit` / `just e2e`; browser JS via `wrapper.php?test=<page>.html` (server: `just serve` or the `.claude/launch.json` "infopedia" config on port 8080).
- Baseline before any task: `just ci` green (253 unit + 90 e2e), `app2_test.js` 101 pass / 1 pre-existing fail (`has prefix label`).
- Commits: Conventional Commits (CV2); each message shown to the user before committing (CV4).

/**
 * assets/entry-core.js — pure entry helpers shared by app2.html and vote.html.
 * No DOM access, no fetch. Loaded as plain globals before each page's own script.
 * Moved out of app2.html on 2026-09-26 (CA7: share via assets, never copy-paste;
 * CA18: the type vocabulary is defined exactly once).
 */

// ── Key helpers ───────────────────────────────────────────────────────────────
function fullKey(topic, nodeId) {
    return topic + ("/" === topic ? "" : "/") + nodeId;
}
function splitKey(key) {
    const lastSlash = key.lastIndexOf("/");
    if (lastSlash <= 0) return ["/", key.replace(/^\//, "")];
    return [key.substring(0, lastSlash), key.substring(lastSlash + 1)];
}

// ── Type suffix ───────────────────────────────────────────────────────────────
// Order matters: two-char suffixes ("!-", "??", "--") must win over their one-char prefix.
function getTypeFromMessage(message) {
    for (const t of [">", "!-", "??", "!", "?", ".", "@", "--"]) {
        if (message && message.endsWith(t)) return t;
    }
    return "";
}
function matchType(message, type) {
    const current = getTypeFromMessage(message);
    if (current === type) return message;
    if (!current) return message + type;
    if (type === "--") return message + type;
    return message.slice(0, -current.length).trim() + type;
}

// ── Type vocabulary (CA18) ────────────────────────────────────────────────────
const TYPE_DEFS = {
    "!-": { label: "Fake",       cssClass: "fake",       color: "#f44336", iconClass: "fa-circle-xmark"    },
    "!":  { label: "Fakt",       cssClass: "fakt",       color: "#4CAF50", iconClass: "fa-circle-check"    },
    "??": { label: "Gegenfrage", cssClass: "gegenfrage", color: "#2196F3", iconClass: "fa-right-left"      },
    "?":  { label: "Unklar",     cssClass: "unklar",     color: "#FF9800", iconClass: "fa-circle-question" },
    ".":  { label: "Meinung",    cssClass: "meinung",    color: "#888",    iconClass: "fa-comment"         },
    "@":  { label: "Quelle",     cssClass: "meinung",    color: "#888",    iconClass: "fa-link"            },
    ">":  { label: "Thema",      cssClass: "fakt",       color: "#4CAF50", iconClass: "fa-folder-open"     },
};
const TYPE_DEF_DEFAULT = { label: "Eintrag", cssClass: "meinung", color: "#888", iconClass: "fa-circle-dot" };

function getTypeDef(message) {
    const suffix = getTypeFromMessage(message);
    const base = TYPE_DEFS[suffix] || TYPE_DEF_DEFAULT;
    return { ...base, suffix };
}

// ── HTML escaping ─────────────────────────────────────────────────────────────
function escapeHtml(s) {
    return String(s).replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;");
}

// ── Debounce (per-key, ms window) ─────────────────────────────────────────────
const _debounceMap = {};
function debounceKey(key, ms) {
    const now = Date.now();
    if (_debounceMap[key] && now - _debounceMap[key] < ms) return false;
    _debounceMap[key] = now;
    return true;
}
